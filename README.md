# 深海摸金（Deep Sea Scavenger）V0.1.0

2D 横版海底摸金生存游戏。有限体力 + 有限背包 + 高价值宝物 + 深海危险 + 安全撤离。

> 每次下海都是一次赌博：你能不能在体力耗尽、鲨鱼追上之前，把更值钱的宝物带回岸上？

---

## 获取与开始游戏（玩家看这里）

**方式一：直接玩（推荐，无需安装任何东西）**

1. 打开本仓库的 GitHub 页面 → 右侧 **Releases** → 最新版本（V0.1.0）
2. 下载附件 `DeepSeaScavenger-v0.1.0-win64.zip`，解压到任意文件夹
3. 双击 `DeepSeaScavenger.exe` 开始游戏

> 需要 64 位 Windows 10/11；首次运行如被 SmartScreen 拦截，点「更多信息 → 仍要运行」。
> 存档不在游戏文件夹里，删掉游戏目录**不会**丢进度。

**方式二：源码运行（想看/改代码的人）**

1. 安装 [Godot 4.3 stable](https://godotengine.org/download)（普通版即可，约 100MB）
2. 下载本仓库（绿色 Code 按钮 → Download ZIP，或 `git clone`）
3. 打开 Godot → 「导入」→ 选择项目根目录的 `project.godot` → 等待资源导入完成
4. 按 **F5** 运行

## 更新方式

- **玩家（方式一）**：到 Releases 重新下载最新版压缩包，解压覆盖即可。存档保存在系统目录
  （`%APPDATA%\Godot\app_userdata\深海摸金\`），与游戏文件无关，覆盖不会丢进度。
- **开发者（方式二）**：在本目录执行 `git pull` 拉取最新代码，再用 Godot 打开工程即可
  （首次打开会自动重新导入资源）。`git pull` 只更新代码和资源，不会动你的本地存档。
  注意：`git pull` 拿到的是源码，必须用 Godot 运行；下载 exe 的玩家请走 Releases。

## 环境与运行（开发者）

- **Godot 版本**：4.3 stable（`tools/Godot_v4.3-stable_win64_console.exe`，仓库未附带时请从 godotengine.org 下载 4.x）
- **打开工程**：Godot 编辑器 → 导入 → 选择本项目根目录的 `project.godot`
- **运行游戏**：编辑器中按 F5；或命令行：
  ```bash
  Godot_v4.3-stable_win64_console.exe --path . 
  ```
- **打包发布**：本仓库已含 `export_presets.cfg`（Windows 单文件 exe，内嵌资源），
  安装 4.3 导出模板后执行：
  ```bash
  Godot_v4.3-stable_win64_console.exe --headless --export-release "Windows Desktop" build/DeepSeaScavenger.exe
  ```
- 渲染使用 `gl_compatibility`，对老显卡友好；窗口 1280×720，支持缩放，UI 自适应。

## 玩法循环

**准备（荒岛）→ 下潜 → 搜刮 → 风险决策 → 撤离 → 出售 → 升级 → 再次下潜**

- 荒岛是安全区：不耗体力，可完全恢复。左侧木牌「下潜点」进入海底。
- 海底地图 5120×1024，从左到右三档风险：
  - **区域 A · 近岸浅滩**：古铜币包 / 银质餐盘，无鲨鱼，用于练手。
  - **区域 B · 沉船区域**：银质餐盘 / 沉船金杯，2 条鲨鱼巡逻，沉船残骸与礁石提供掩体与绕行路线（底层爬行道 / 中层航道 / 上层绕行）。
  - **区域 C · 深层洞穴**：金杯 / 诅咒神像，2 条鲨鱼，最深处有悬挑岩龛（龛下可藏身搜索，挡住上方巡逻视线）。
- 每次下潜用随机种子抽取"海况"：三个区域各有 3 套手工布局变体（礁石群/乱石阵/沙丘平原、沉船残骸/双桅废墟/尖塔礁林、悬挑岩窟/石柱迷宫/深渊窄廊），共 27 种组合；宝物点每区域再随机激活一部分（A4/B4/C3）。所有变体保证底层安全通道贯通，结算界面显示本次海况编号。
- **宝箱稀有度可视分层**：光晕颜色 = 宝物成色，金杯/神像有更大光晕与光柱，远远就能判断"值不值得冒险"。
- **返航预估**：HUD 实时显示"返航预计消耗 X 体力"，不足时红色警告——贪还是撤，一眼可见。
- **撤离**：游回最左侧金色光柱按 E，宝物才真正入库；**体力耗尽或生命归零 = 失败，本次战利品全部丢失**（已储存的额度、材料、升级、造船进度不受影响）。
- 背包默认 8 格，占用 ≥6 格触发负重（速度 -10%、消耗 +20%）。携带诅咒神像时鲨鱼发现距离 +50%，丢弃即解除。
- 鲨鱼咬人后强制脱离 1.1 秒并把玩家击退，同一鲨鱼咬击间隔 1.6 秒——被咬不等于死，利用击退动量与掩体甩掉视线（2.2 秒）即可脱身。追逐期间有紧张低音提示。
- 区域 C 有深度黑暗（玩家携带潜水灯），能见度即风险；体力低于 20% 有红晕脉冲与心跳声。
- 结算界面显示本次下潜用时。
- 目标：出售宝物换取交易额度 → 购买木材/铁件/帆布 → 在船坞造出小帆船（通关 v0.1）。

## 目录结构

```text
project.godot            工程配置（输入映射 / 分辨率 / autoload）
scenes/                  主菜单、荒岛、海底、玩家、鲨鱼、宝箱
scenes/ui/               HUD、背包、结算、暂停、商人、升级、船坞
scripts/
  balance.gd             全部可调数值（速度/体力消耗/鲨鱼参数/负重/刷新数量）
  item_db.gd             宝物/物资/升级/造船/区域权重 数据表
  map_data.gd            海底地图数据（共享骨架 + 3区域×3布局变体 + 通道校验）
  game_state.gd          全局状态（永久进度 + 单次下潜临时数据）
  save_manager.gd        JSON 存档（user://deepsea_scavenger_save.json）
  sfx.gd                 音效管理
  player.gd / shark_ai.gd / treasure_chest.gd / underwater.gd / island.gd ...
  ui/                    全部界面脚本
assets/ui/theme.tres     全局中文主题（系统字体回退：雅黑/黑体/苹方/Noto）
assets/audio/            程序生成的占位音效（tests/gen_audio.gd 可重新生成）
assets/sprites/kenney_fish/  Kenney Fish Pack 2.0 精灵（CC0，见目录内 LICENSE.txt）
tests/                   自动化检查（见下）
```

## 数值配置位置

- 移动/体力/鲨鱼/负重/刷新数量：`scripts/balance.gd`
- 宝物价值与格子、物资价格、升级费用与效果、造船需求、区域掉落权重：`scripts/item_db.gd`
- 地图地形、宝物点、鲨鱼巡逻区：`scripts/map_data.gd`
- 存档内容结构：`scripts/game_state.gd` 的 `serialize()/apply_save()`

## 已知问题

- 音效为程序生成的占位音；无独立音乐。
- 环境层使用 [Kenney Fish Pack 2.0](https://opengameart.org/content/fish-pack-0)（CC0 公有领域，可自由商用，无需署名）；潜水员、鲨鱼、宝箱、商人仍为程序绘制的多边形占位。
- 新增布局变体时必须同步通过 `tests/run_tests.gd` 的变体校验（宝物点 / 巡逻带 / 三条安全通道）。
- 暂停菜单「返回主菜单」会丢弃未撤离的本次宝物（有二次确认）。
- 强制退出游戏进程时控制台可能打印一条无害的「resources still in use」。
- 鲨鱼追逐采用直线转向 + 碰撞滑动，未做绕障寻路；咬人后有 1.1 秒强制脱离期作为平衡补偿。
- 区域C黑暗与潜水灯、宝箱稀有度光效与素材化地形在无界面模式下无法目视验证，参数基于推算，真人体验可能需要微调。
