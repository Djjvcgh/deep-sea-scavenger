# 深海摸金（Deep Sea Scavenger）V0.4.0

2D 横版海底摸金生存游戏。有限体力 + 有限背包 + 高价值宝物 + 深海危险 + 安全撤离。

> 每次下海都是一次赌博：你能不能在体力耗尽、鲨鱼追上之前，把更值钱的宝物带回岸上？
> V0.4 起每次下潜的海况主题、沉船、洞穴与 Boss 都不同——为了下一件传说宝物，再潜一次。

---

## 获取与开始游戏（玩家看这里）

**方式一：直接玩（推荐，无需安装任何东西）**

1. 打开本仓库的 GitHub 页面 → 右侧 **Releases** → 最新版本（V0.4.0）
2. 点击说明中的下载链接（或到 `dist/` 目录）下载对应 win64 压缩包，解压到任意文件夹
3. 双击 `DeepSeaScavenger.exe` 开始游戏

> 需要 64 位 Windows 10/11；首次运行如被 SmartScreen 拦截，点「更多信息 → 仍要运行」。
> 存档不在游戏文件夹里，删掉游戏目录**不会**丢进度。V0.1 存档会自动迁移。

**方式二：源码运行（想看/改代码的人）**

1. 安装 [Godot 4.3 stable](https://godotengine.org/download)（普通版即可，约 100MB）
2. 下载本仓库（绿色 Code 按钮 → Download ZIP，或 `git clone`）
3. 打开 Godot → 「导入」→ 选择项目根目录的 `project.godot` → 等待资源导入完成
4. 按 **F5** 运行

## 更新方式

- **玩家（方式一）**：到 Releases（或 `dist/` 目录）重新下载最新版压缩包，解压覆盖即可。存档保存在系统目录
  （`%APPDATA%\Godot\app_userdata\深海摸金\`），与游戏文件无关，覆盖不会丢进度。
- **开发者（方式二）**：在本目录执行 `git pull` 拉取最新代码，再用 Godot 打开工程即可
  （首次打开会自动重新导入资源）。`git pull` 只更新代码和资源，不会动你的本地存档。
  注意：`git pull` 拿到的是源码，必须用 Godot 运行；下载 exe 的玩家请走 Releases / `dist/`。

## 环境与运行（开发者）

- **Godot 版本**：4.3 stable（`tools/Godot_v4.3-stable_win64_console.exe`，仓库未附带时请从 godotengine.org 下载 4.x）
- **打开工程**：Godot 编辑器 → 导入 → 选择本项目根目录的 `project.godot`
- **运行游戏**：编辑器中按 F5；或命令行：
  ```bash
  Godot_v4.3-stable_win64_console.exe --path . 
  ```
- **打包发布**：本仓库已含 `export_presets.cfg`（Windows 单文件 exe，内嵌资源），
  安装 4.3 导出模板后执行：
  ```bash
  Godot_v4.3-stable_win64_console.exe --headless --export-release "Windows Desktop" build/DeepSeaScavenger.exe
  ```
- 渲染使用 `gl_compatibility`，对老显卡友好；窗口 1280×720，支持缩放，UI 自适应。

## 玩法循环

**准备（荒岛）→ 下潜 → 搜刮 → 风险决策 → 撤离 → 出售 → 升级 → 再次下潜**

- **荒岛（2600px 长岛）**：安全区，不耗体力，可完全恢复。摄像机平滑跟随左右探索：
  左侧海滩木牌「下潜点」进入海底，沿途分布神秘商人、装备工作台与右侧海湾的船坞。
- **海域主题（每潜必不同）**：种子抽取「沉船海域 / 洞穴海域 / 深渊海域」三选一，
  决定本次出没的 Boss 并偏置沉船/洞穴生成；HUD 与开场提示都会标明主题，海况编号可复现、可分享。
- **世界布局（每潜必不同）**：种子决定区域排布方式——
  **横列海域**（A 左 → B 中 → C 右）或**纵深层海域**（按深度上下划分：A 上层阳光带 / B 中层搁架 /
  C 深渊湖底，沉船搁在中层搁架上、洞穴挂在搁架底部与湖底，明暗沿深度变化，两侧竖井 + 湖底爬行道三条安全通道）。
- **种子化骨架**：C 区巨岩的西缘位置、底缘高度、倒垂岩柱每潜都不同；纵向布局的中层搁架缺口位置随机；
  地形模块（沙丘/岩塔/石拱/沙脊/沙阶/墙垛/倒悬岩簇）每潜 5~10 个——骨架本身每次都长不一样。
- **海底地图 5120×1024**，从左到右三档风险：
  - **区域 A · 近岸浅滩**：低阶宝物，无鲨鱼，用于练手。
  - **区域 B · 沉船区域**：银器 / 金杯，鲨鱼巡逻，可探索沉船多在此区。
  - **区域 C · 深层洞穴**：金杯 / 诅咒神像，深渊巨影的领域，巨岩下方挂着可探索的悬空洞窟。
- **随机沉船遗址（0~2 艘）**：普通商船（60%，安全，银器金杯）、海盗船（30%，有舱壁隔出船长室，
  产出船长罗盘 / 黄金六分仪，周围有鲨鱼巡逻）、祭祀船（10%，祭祀遗物 / 诅咒宝物，
  开箱会惊动鲨群）。锚点共 7 处（每潜至多占一处）并带 ±50px 位置抖动，船体有甲板破口与两舷舱门，
  可游入舱内搜索，同种子必然复现。
- **随机洞穴（2~4 处）**：海床岩洞与深渊悬洞两类形态；藏身岩洞（纯掩体）、隐藏洞穴（洞内宝箱）、
  深海危险洞穴（高级宝箱，洞穴主题的海蛇潜伏于此）。岩壁会挡住鲨鱼视线——藏身不等于无敌，
  但隔着岩壁鲨鱼既发现不了你也咬不到你。
- **海面换气**：贴近与天空相通的开放海面时停止体力消耗，每秒恢复 8 点（HUD 显示"正在换气"，
  体力条绿色脉冲）；洞穴顶盖、岩层与沉船甲板下方不算海面。15 分钟下潜限时不变。
- **三角洲式摸金**：每个宝箱开出 **1~4 件随机物品**，每件有独立品质（破损 ×0.6 / 标准 ×1.0 / 精良 ×1.4 / 完美 ×2.0），
  区域越深品质与件数期望越高；开箱弹出拾取界面，逐件决定拿什么——**背包装不下的留在箱内，按 E 可随时重新打开取走**。
- **小型容器**：海底散布海贝、垃圾袋（每局约 15 个），搜索快、掉低价值物品与**皮革**。
- **死亡掉落可找回**：失败后本次战利品散落在海床原位；下次下潜开场有声呐提示「遗落物袋」位置。
- **背包打造**：默认 8 格 → 皮革背包 10 格 → 加固背包 12 格，在工作台用海底材料打造。
- **商人物资交换**：材料可按 8 折回售换额度，也可用额度购买。
- **兵器系统**：工作台用铁件×2+木材×1 打造鱼叉（空格刺击，自动瞄准）。鲨鱼 3 点生命，击杀掉皮革。
- **主题 Boss（每次下潜只出一个）**：
  - **深渊海域 · 深渊巨影**：携带诅咒神像约 12 秒后苏醒，触拍有红色预警圈，16 点生命；逃出区域 C 潜回。
  - **沉船海域 · 幽灵船长**：进入沉船长室显形，红线预警后短距冲刺，会放出无害的幽灵投影；10 点生命；远离沉船即遁回。
  - **洞穴海域 · 洞穴海蛇**：潜伏在危险洞穴，锁定方向红线预警后沿该方向突袭；12 点生命；远离巢穴即潜回。
  - 击杀主题 Boss 均掉落大额战利品袋（完好品质遗物）。不触发、不打也可以完全回避，安全撤离永远是选项。
- 区域 C 有深度黑暗（玩家携带潜水灯）；体力低于 20% 有红晕脉冲与心跳声。
- 目标：出售宝物换取交易额度 → 购买材料 → 在船坞造出小帆船（通关目标）。

## 已实现功能

- 主菜单（新游戏/继续/设置音量与全屏/退出）+ 中文 UI
- 荒岛 2600px + 陆地摄像机平滑跟随（边界正确停住），下潜点/商人/工作台/船坞全可步行到达

- **海域主题**：沉船/洞穴/深渊三选一，决定 Boss 与生成偏置，HUD 常显
- **三主题 Boss**：深渊巨影（神像触发）/ 幽灵船长（沉船长室触发）/ 洞穴海蛇（危险洞穴触发），均可用鱼叉击杀掉落大额战利品，也可完全回避

- **小型容器**（海贝/垃圾袋）：快速搜索，掉落低价值物品与皮革
- **死亡掉落可找回**：遗落物袋 + 声呐提示 + 自动合并
- **背包打造**：8 → 10 → 12 格（工作台消耗海底材料）
- 生命 ×3、鲨鱼接触伤害、2 秒无敌、受伤闪红

## 已知问题

- 音效为程序生成的占位音；无独立音乐。
- 环境层使用 [Kenney Fish Pack 2.0](https://opengameart.org/content/fish-pack-0)（CC0 公有领域，可自由商用，无需署名）；
  潜水员、鲨鱼、宝箱、商人、沉船与 Boss 仍为程序绘制的多边形占位；物品图标为程序生成的原创像素图。
- 沉船与洞穴只在 A/B/C 海床与 C 区岩体下的经验证锚点/区间生成，B2 石柱礁林、B3 沉没货舱等拥挤变体不会出现沉船；
  石柱迷宫（C1）不会出现悬空洞穴——生成器已按主题自动规避。
- 幽灵船长的冲刺不做地形碰撞检测，极端情况下可能短暂穿入岩壁后再滑出。
- 暂停菜单「返回主菜单」会丢弃未撤离的本次宝物（有二次确认）。
- 强制退出游戏进程时控制台可能打印一条无害的「resources still in use」。
- 鲨鱼追逐采用直线转向 + 碰撞滑动，未做绕障寻路；咬人后有 1.1 秒强制脱离期作为平衡补偿。
- 区域C黑暗与潜水灯、素材化地形在无界面模式下无法目视验证，参数基于推算，真人体验可能需要微调。
- 开箱拾取界面期间移动保持锁定（刻意保留的搜刮风险窗口），鲨鱼仍会进攻。
