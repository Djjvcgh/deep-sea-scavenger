# 正式关卡美术圣经（Formal Level Art Bible）

> 本文档把黑潮号测试关卡验证过的视觉方向（V0.5-2/3 阶段）系统化为**正式关卡**的美术规范。
> 实现载体：`scripts/level_theme.gd`（模块库 + 房间类型→主题映射），贴图管线
> `tests/gen_scenery_v05.gd`（59 张原创程序像素贴图）+ Kenney Fish Pack（CC0）。
> 前后对比截图：`screens/formal_before/` vs `screens/formal_after/`。

## 1. 风格关键词

像素风 · 暗黑海洋奇幻 · 破败木质沉船 · 高可读性横版探索 · 宝物高价值感 · 克苏鲁式未知感 ·
航海探险 UI（木纹 + 黄铜 + 描边文字）

一句话锚点（全关卡通用）：**"被海水浸泡的木质世界里，金色的东西值得冒险。"**

## 2. 调色板（palette_v05，全关卡统一）

| 色组 | 主色 | 信号语义 |
| --- | --- | --- |
| 深海黑蓝 `#0E1B2E` | 越深越暗的基底 | 危险梯度 |
| 海水青蓝 `#1E5666` | 水体与 UI 强调 | 中性 |
| 远景灰蓝 `#3E5568` | 礁岩/沉积/远景 | 环境 |
| 木质棕褐 `#6B4A2A` | 船体/栈道/摊位/面板 | 人造物 |
| 宝物暖金 `#F2C53D` | 宝箱/金堆/漏光/估值 | **值钱** |
| 危险暗红 `#C43B30` | 警告/炉火/异化符文 | **要命** |
| 荧光青绿 `#66F0D9` | 密室线索/发光藻/独特遗物 | **秘密** |
| 异化紫 `#8A3AA8`（新增，仅区域C） | 晶脉/黑海草/祭坛 | 深层诅咒 |

硬规则：金色只给值钱物与回家路；青绿只给秘密；红色只给危险；紫色只在区域 C。

## 3. 角色与场景比例

- 逻辑分辨率 1280×720，相机默认 **zoom 1.5**（V0.5-3 对比 1.3/1.5/1.7 选定）。
- 环境件 1 素材像素 = 2 逻辑像素，全部 NEAREST 采样，禁止混用像素密度。
- 基准：宝箱 60×56、木桶 52×60、船肋 36×184、玩家 ~44×14（水平游动）。
- 所有环境件自带 1px 深色描边（`#1B1410` 级）保证暗背景剪影可读。

## 4. 岛上场景风格规范

- 基调：暖沙 + 草地边条 + 椰树；人造物全部为木质（栈道/摊位/工作台/船坞）。
- 功能区 = 模块实体，不依赖文字：下潜=栈桥+红金浮标灯；商人=红白条纹雨棚摊位+货品+暖光；
  工作台=厚桌+铁砧+柴堆+炉火光；船坞=滑道+桩柱+桶绳+进度小船。营火=据点人气核心。
- 木牌（signpost 贴图 + 描边短标签）只作辅助定位，不是唯一识别手段。
- 天空/海/云保持既有渐变与波浪线；远景不再扩展（岛屿是"家"，安全明亮）。

## 5. 浅海区域（Zone A）风格规范

明亮 · 开阔 · 低风险低收益。海况色调 `_sand_tint` 偏暖微调。
模块：sand_tile 海床条（逐行加深）、coral_a/b、Kenney 海草、wreck_debris 小残骸、
浅海光柱、鱼群、远景礁影（视差 0.15×）+ Kenney 中景（0.45×）。
密度规则：每 600px 至少 2 组植被/珊瑚点缀；禁止连续一屏只有沙。

## 6. 沉船区域（Zone B）风格规范

深蓝水体 + 棕褐木质 · 结构密集 · 舱室感。房间类型映射（真实代码 `LevelTheme.room_theme`）：

| room_type（生成器 kind） | 美术主题 | 模块组合 |
| --- | --- | --- |
| merchant | wreck_storage | 背板+船肋+桶/箱/绳+油灯+微粒 |
| pirate（宽 interior） | wreck_storage | 同上 |
| pirate captain_room | captain_room | 书桌+神龛+金堆+油灯金光 |
| ritual | ritual_shrine | 神龛青绿光+鱼骨+冷背板 |
| （开阔段） | wreck 散件 | wreck_debris/barrel/rope_coil 散布 |

墙体 = hull_wall_a/b 平铺（规律掺破损变体）；宝箱高亮呼吸保留；金色焦点只落在 spots 上。

## 7. 洞穴区域（Zone C）风格规范

更暗 · 更窄 · 掩体多 · 高收益高风险。房间类型映射：

| room_type | 美术主题 | 模块组合 |
| --- | --- | --- |
| shelter（含 hang_） | cave_hideout | cave_wall + 发光藻×4 + 暗幕 |
| treasure（含 hang_） | cave_treasure | cave_wall + 发光藻×6（更亮）+ 暗幕 |
| danger（含 hang_） | cave_danger | cave_wall + 发光藻（红移）+ 黑海草 + 鱼骨 |
| （开阔段） | deep_hazard | corrupt_rock 紫晶 + 黑海草 + 祭坛 + 紫晕微粒 |

洞穴墙体 = cave_wall 湿岩层平铺；区域 C 岩体 28% 概率替换为异化岩（紫脉）。

## 8. 危险/深层区域风格规范（第一版简化）

- 区域 C 环境 tint 乘 `Color(0.9, 0.92, 1.0)` 偏冷；CanvasModulate 深度压暗已有（0.5,0.57,0.7）。
- 异化语言三件套：corrupt_rock（紫脉晶石）、seaweed_black、altar（暗红符文微光）。
- 巨影剪影 `_shadow` 保留（克苏鲁暗示）；祭坛每张图至多 1 座（＞380px 开阔带才放）。

## 9. HUD 风格延续规则

- 水下 HUD（V0.5-3 航海风）原样延续：木纹九宫格面板 + 图标化生命/体力/背包/估值 +
  沙漏倒计时 + E 键帽交互提示 + 描边文字。
- 岛上状态栏：同款木纹面板（`UICommon.wood_stylebox`）。
- 区域名：切换时 HUD 短暂显示（2.4s 淡出）；场景内不放置常驻文字标签。
- 撤离点：红金浮标灯标 + 金色光束（两关卡同语言）。

## 10. 装饰密度和留白规则

- 焦点留白：宝箱/神龛/祭坛周围 60px 内不放大型遮挡件，光晕即引导。
- 房间密度：每 220px 一根船肋；每舱 2-4 件货件 + 1 灯光焦点 + 1 微粒簇。
- 开阔区密度：每 600px 一组主题散件；同屏同种贴图不超过 3 连（tile 函数按 (ix·7+iy·3)%6 掺变体）。
- 禁止事项：无贴图纯色矩形可见；无意义重复平铺（无变体）；漂浮文字标签表达区域身份；
  混用非本管线的像素密度/光影风格。

## 11. 管线与复用（工程约定）

- 所有正式关卡视觉走 `LevelTheme`：`paint_solid`（碰撞矩形铺装）、`decorate_room`
  （房间类型→主题）、`island_*`（基地模块）；黑潮号手工关卡保留独立 dressing（更高定制密度）。
- 新贴图一律进 `tests/gen_scenery_v05.gd`（幂等生成），不入第三方来源（Kenney 除外，CC0）。
- 海况随机 tint（water/sand/rock）在 `_roll_layout` 抽取，透传给 `paint_solid`，保证同种子同图。
