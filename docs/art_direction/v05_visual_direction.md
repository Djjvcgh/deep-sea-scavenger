# V0.5 视觉方向（Visual Direction）

> 本文档先于实现建立。样板对象：《黑潮号残骸》**船长货舱**（x2920–3240 / y895–1030 一带）。
> 配套色板样张：`docs/references/style/palette_v05.png`（自制）。
> 参考来源与版权边界见 `docs/references/REFERENCE_CHECKLIST.md`。

## 1. 目标风格关键词

暗黑海洋奇幻 · 深海恐惧 · 破败沉船 · 像素风 · 高可读性横版探索 · 宝物高价值感 · 克苏鲁式未知感

一句话锚点：**"一间被海水浸泡三十年的船长舱室"——木质结构还在呻吟，金子还在发光，但有什么东西不该在这里。**

## 2. 参考拆解（只借鉴语言，不搬图）

### DREDGE（氛围 / 宝物价值感 / 深海恐惧）
- **借鉴**：恐惧不靠怪物贴脸，靠"环境不合常理"——颜色突然变冷、光源该亮不亮、构图留出大片不可见的暗部。宝物展示用"深底色 + 暖金物品 + 品质分层描边"制造价值感。
- **落地**：舱内整体压暗（CanvasModulate 已有），金色只出现在宝物、漏光、烛火三处；密室区域用荧光青绿作"不该存在"的颜色信号。

### DAVE THE DIVER（水下可读性 / 场景吸引力）
- **借鉴**：能见度渐变（浅亮深暗但仍能读出剪影）；生物与地形轮廓永远清晰；危险与奖励用色相区分。
- **落地**：所有环境件统一加 1px 深色描边；可行走区域与墙体之间保持明度差 ≥ 25%；宝箱高亮保留呼吸脉冲。

### Dead Cells（房间层次 / 区域身份）
- **借鉴**：区域身份三件套 = **墙材质 + 主色 + 光源**；房间按 前（剪影遮挡）—中（玩法层）—后（氛围层）三层组织；同屏色相收敛在 3 个以内。
- **落地**：船长货舱三件套 = 纵向船肋木墙 + 暖褐主色 + 悬挂油灯暖光；背景层（暗板墙、舷窗）— 玩法层（宝箱、机关）— 前景层（海草、缆绳，透明度 ≤ 0.85 且只放边缘）。

### SteamWorld Dig 2（岔路 / 秘密 / 地形引导）
- **借鉴**：秘密永远有"一点点不对"——异色矿石、不该有的裂缝、光源方向暗示出口；岔路用"看得见但暂时到不了"引导探索。
- **落地**：暗门保留青色细缝漏光脉冲，并在神龛后加"可疑角落"专属 dressing（倾斜搁架 + 缝隙微光 + 散落金件）；撤离方向用金光束暗示（已有）。

| 宝物暖金 | `#F2C53D` | `#C99420` | `#FFE08A` | 宝箱高亮、金库漏光、估值数字、完美品质 |
| 危险暗红 | `#C43B30` | `#8A2420` | `#E05A4E` | 鲨鱼警报、低生命、破损品质反衬 |
| 荧光青绿 | `#66F0D9` | `#3FBFAE` | `#9FF7EA` | 密室线索、神龛蓝火、独特遗物 |

规则：
- 同屏色相 ≤ 3 组（木褐 + 深海蓝 + 一个"信号色"：金 / 红 / 青绿按语义取一）。
- 金色只在"值钱的东西"和"回家的路"上出现；青绿只在"秘密"上出现；红色只在"要命的东西"上出现。
- 越深越暗：区域身份靠"暗的方式"区分（甲板冷亮 / 舱内暖暗 / 夹层近黑）。

## 4. 像素规格与显示规则

- **逻辑分辨率**：1280×720（`canvas_items` 拉伸，保持现状，不动工程设置）。
- **像素密度**：环境件 **1 素材像素 = 2 逻辑像素**（生成半分辨率贴图 ×2 渲染）；图标类 1:1。
- **采样**：所有新贴图 `texture_filter = NEAREST`，禁止模糊缩放。
- **尺寸基准**（素材像素，×2 后为场景逻辑尺寸）：

| 对象 | 素材尺寸 | 场景中 | 说明 |
| --- | --- | --- | --- |
| 玩家 | 现状多边形 ~30×44 | 不动 | V0.5 不重制角色 |
| 鲨鱼 | 现状多边形 | 不动 | 同上 |
| 宝箱（升级后） | 26×22 | 52×44 | 关/开两态 |
| 木桶 | 22×26 | 44×52 | 常态 + 敞口两态 |
| 货箱 | 24×20 | 48×40 | 单态 |
| 船肋 | 16×88 | 32×176 | 微旋转 ±4° |

| 斜梁 | 140×10 | 280×20 | 断裂端 + 捆扎 |
| 航海桌 | 40×28 | 80×56 | 日志机关底座 |
| 神龛 | 26×32 | 52×64 | 拱形 + 烛台 |
| 绞盘 | 22×24 | 44×48 | 链条沿地面延伸 |

- **字体与描边**：默认字体沿用；HUD/面板文字 ≥ 15px；正文颜色 `UICommon.TEXT`，次要 `DIM`；标题金色；无衬线、不斜体。HUD 关键数字（倒计时、估值）用金色/危险色替代加粗。
- **描边规则**：环境件贴图内自带 1px 深色（`#1B1410` 级）外描边；角色/宝箱已有对比底，不加。

## 6. 样板房验收口径（对应任务十一）

隐藏所有区域文字标签后，船长货舱应满足：
1. 船体轮廓（肋骨状的重复竖向结构 + 壳板墙）一眼可辨"沉船内部"；
2. 暖金光斑所在处 = 宝物（金库 / 漏光 / 烛火同语言）；
3. 神龛后的暗角"值得探索"（青绿微光 + 不合常理的倾斜搁架）；
4. 可行走路线靠明度差与地面沉积物走向呈现，不靠文字。
